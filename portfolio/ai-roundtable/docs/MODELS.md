# AIモデル管理

モデル名、能力、価格は変わるため、この文書へ固定的な最新情報や料金を断定しません。実装時は更新可能な設定・管理表を正本とし、この文書は項目と運用方針を定義します。

## 管理項目

| 項目 | 内容 |
| --- | --- |
| provider | OpenAI、Gemini、Claudeなど |
| model_id | APIへ渡す正確なID |
| display_name | UI表示名 |
| purpose | 回答、要約、議長、レビューなど |
| quality_tier | 節約、標準、高品質への対応 |
| speed_class | 条件付きの相対区分 |
| input/output_price | 単価、単位、通貨、適用日 |
| context_limit | 公式情報の確認日付き上限 |
| capabilities | テキスト、画像、ツールなど |
| strengths/limits | 評価で確認した得意分野と制約 |
| status | active、deprecated、disabled |
| updated_at/source | 更新日と確認元 |

実測していない品質、速度、得意分野を断定しません。

## 品質モード

- 節約: 費用と速度を優先する有効モデル
- 標準: 一般用途の既定モデル
- 高品質: 難しい比較・議長用途向け。予算上限は維持
- カスタム: 利用者が許可されたモデルから選択

モードは固定モデルIDをコード中へ埋め込まず、設定から解決します。

## 更新と廃止

1. 公式情報で能力、価格、廃止日を確認する
2. [BENCHMARK](BENCHMARK.md) の計画に沿って候補を評価する
3. 段階的に既定値を変更し、監視とロールバック手段を用意する
4. 保存済みセッションには実際に使ったモデルIDと設定版を残す
5. 廃止モデルは新規選択を止め、互換候補と差異を案内する

モデルが利用不能な場合は、無断で高額・低品質なモデルへ切り替えず、設定されたフォールバックと予算の範囲で動作します。
