# プロンプト管理

現在、外部AI用のプロンプトは未実装です。この文書は導入時の管理方針です。

## 種類

- 各AIへの基本回答プロンプト
- 回答の比較・要約プロンプト
- 議長AIプロンプト
- 相互レビュープロンプト
- 賛成・反対・専門家など役割プロンプト
- AI社員の役職別プロンプト

## 管理方針

- 実行コードへ長文プロンプトを散在させず、`app/prompts/` など一箇所で管理する
- プロンプトID、版、用途、対象言語、変更理由、更新日を追跡する
- 実行結果にプロンプト版を関連付け、後から比較可能にする
- 秘密情報、APIキー、実ユーザーデータをプロンプト例へ記載しない
- システム指示とユーザー入力を構造的に分離する
- 外部文章を命令として無条件に採用せず、プロンプトインジェクションを想定する

## テスト

- 入力組み立て、変数不足、最大長、安全なエスケープを自動テストする
- 固定質問セットで期待する構造、禁止事項、不確実性表示を評価する
- 出力文言の完全一致ではなく、必須項目と安全条件を確認する
- 変更前後を同じモデル設定で比較し、品質・速度・費用への影響を記録する
- 実測値を記載する場合は条件、日付、試行数、限界を残す

評価計画は [BENCHMARK](BENCHMARK.md) を正本とします。

## 多言語対応

初期は日本語を優先します。将来は言語別テンプレートまたは言語非依存の構造と翻訳層を比較し、同一プロンプト内の条件分岐を増やしすぎない方針です。言語ごとに品質と安全性を評価します。
