# ロードマップ

## 運用方法

優先度は `P0`（現在のリリース必須）、`P1`（次に重要）、`P2`（有用）、`P3`（長期構想）です。日程より完了条件を重視し、常に動く小さな状態を保ちます。

## 現在地点

| 項目 | 状態 |
| --- | --- |
| 質問入力画面 | 実装済み |
| FastAPIへの送信とエコー応答 | 実装済み |
| 入力・通信の基本エラー表示 | 実装済み |
| OpenAI・Gemini・Claude接続 | 未実装 |
| 回答比較・要約、料金概算 | 未実装 |

## MVP（P0）

| 段階 | 内容 | 完了条件 |
| --- | --- | --- |
| 0 | Web基盤 | 質問送受信、1〜2,000文字検証、基本テストが動く（完了） |
| 1 | OpenAI | `.env` のキーで回答でき、タイムアウト・失敗・モックを扱える |
| 2 | Gemini・Claude | 各社を独立したサービスとして接続し、3回答を表示できる |
| 3 | 並列化 | 3社を並列実行し、一部失敗でも成功回答を表示できる |
| 4 | 比較・要約 | 共通点、相違点、長所、短所、推奨案、注意点を表示できる |
| 5 | 料金概算 | モデルと入出力使用量から質問単位の概算と合計を表示できる |
| 6 | MVP完了 | 主要な成功・失敗経路のテスト、利用上の注意、秘密情報対策がある |

## 短期（P1）

- 質問・回答履歴、お気に入り
- Markdown、PDF、CSV出力
- モデル選択と節約・標準・高品質モード
- 月間コスト集計、予算警告
- 監視、相関ID、運用エラーの改善

## 中期（P2）

- ログイン、家族・チーム利用、共有URL
- 検索、タグ、ダークモード
- 音声入力、画像・ファイル入力
- AI同士の相互レビューとライトディベート
- フィードバックと結果の追跡評価
- 安全なプラグイン境界

## 長期（P3）

- 複数ラウンドのAIディベートと議長AI
- AI会議室OS、AI社員株式会社モード
- 社内AI・外部サービス連携、プラグインマーケット
- 個人最適化、意思決定履歴からの改善提案
- SaaS、モバイルアプリ、PWA、オープンソース化の検討

未確定案は [FUTURE_IDEAS](FUTURE_IDEAS.md)、ディベート詳細は [DEBATE_SYSTEM](DEBATE_SYSTEM.md)、費用詳細は [COST_MANAGEMENT](COST_MANAGEMENT.md) を正本とします。
